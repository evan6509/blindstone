# Minecraft 26.3 packet coverage inventory

**Checkpoint:** October 16, 2026. No outgoing gameplay path is currently intercepted. All required runtime concealment paths are release blockers. Normal startup refuses activation; development startup denies player admission.

This inventory was checked against the actual unobfuscated 26.3 sources generated by Loom 1.17.14. It records implementation candidates and known bypass paths, not validated protection. The [generated class-reference index](vanilla-packet-inventory.json) covers 153 clientbound packet classes across protocol states, including 126 in the game protocol. Every class is labeled `not_intercepted`. Lexical references are not a complete call graph; factories, inherited methods, wrapping and custom payload contents need further inspection.

The separate isolated `ClientboundLevelChunkPacketData` prototype has passing codec tests for block/air replacement, section counts, palettes, initial block entities and heightmaps. **That result does not mark the corresponding live packet path implemented.**

## Version-specific research notes

`ClientboundLevelChunkWithLightPacket` is a record in this version. Use its actual components and stream codec; do not copy pre-26.3 constructors/accessor assumptions. `ClientboundLevelChunkPacketData` has a public constructor from `LevelChunk`, a stream codec, and a private composite-data constructor. Its serialization includes cloned real heightmaps when built directly from a real chunk, so merely replacing the block byte array would leave a side channel.

The selected strategy rebuilds a detached chunk representation and uses the public vanilla chunk-data constructor. It copies original biomes, which are outside the seed-secrecy scope. The source of the deepslate gradient is `data/minecraft/worldgen/material_rule/overworld/underground.json` in the pinned game JAR: vanilla uses endpoints 0 and 8; the deterministic prototype step at zero is a documented simplification.

Official background: [Fabric's 26.3 development notes](https://www.fabricmc.net/2026/09/15/263.html), [Fabric networking documentation](https://docs.fabricmc.net/develop/networking), [Loader metadata](https://meta.fabricmc.net/v2/versions/loader/26.3), and [Fabric API metadata](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/maven-metadata.xml). Fabric custom networking is not treated as an interception mechanism for all vanilla paths.
